# EdgeNote

一个适用于 Windows 10 的桌面便签小工具。

## 功能

- 无 Windows 系统标题栏的便签外观
- 窗口可拖动、可调整大小
- 支持左 / 右 / 上 / 下四边贴边
- 贴边后自动隐藏
- 鼠标靠近对应屏幕边缘时自动出现
- 自动保存文字内容
- 自动记忆窗口位置和大小
- 支持总在最前

## 使用

直接运行 `EdgeNote_Frameless_v3.exe` 即可，无需安装 Python 或其他运行库。

> Windows SmartScreen 可能会提示“未知发布者”，因为这个自制 EXE 没有数字签名。

## 文件

- `EdgeNote_Frameless_v3.exe`：Windows 10 x64 可执行程序
- `EdgeNote_native_frameless.c`：对应的 Win32 C 源码
